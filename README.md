# Nomadly — Strategic Intelligence for Space Markets

A modern, high-performance Next.js site for [Nomadly](https://www.nomadly.fr), an innovative strategic intelligence consulting firm democratizing access to global space and telecommunications markets.

## Tech Stack

- **Next.js 16** (App Router)
- **Tailwind CSS v4**
- **TypeScript**
- **Vercel Analytics** + **Speed Insights**
- **Google Fonts** (Syne + DM Sans) via `next/font`

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Homepage
- `/about` — About Us
- `/partners` — Partners & Global Network
- `/features` — Platform Features
- `/faq` — Frequently Asked Questions
- `/blog` — Blog & Insights
- `/contact` — Contact Us

## SEO & AI Discoverability

- JSON-LD structured data (Organization, WebSite, FAQPage schemas)
- Open Graph + Twitter Card metadata with custom OG image
- `robots.txt` allowing all major AI crawlers
- `sitemap.xml` with proper priorities
- `llms.txt` for AI-readable site summary

## Deploy

Hosted on [Vercel](https://vercel.com).
